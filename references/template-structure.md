# Template structure

The authoritative required-file manifest and source-of-truth rules are in [documentation-manifest.md](documentation-manifest.md).

Use the bundled `templates/` directory as output material. Create missing files merge-safely with `scripts/init-project.ps1`, fill known context, mark open decisions as `TBD`, and validate with `scripts/validate-project-docs.ps1`.

Do not treat the template as permission to invent a framework, provider, version, price, metric, deadline, or URL.
