## Riscos Comuns em Projetos

### Técnicos
- [ ] **Escalabilidade** - Sistema não aguenta crescimento
- [ ] **Segurança** - Vulnerabilidades, data breach
- [ ] **Dependências** - Serviço externo fica indisponível
- [ ] **Débito técnico** - Código difícil de manter
- [ ] **Performance** - Aplicação lenta

### Negócio
- [ ] **Market fit** - Produto não resolve problema real
- [ ] **Competição** - Concorrente lança feature similar
- [ ] **Pricing** - Preço não adequado ao mercado
- [ ] **Churn** - Utilizadores cancelam rapidamente

### Operacionais
- [ ] **Recursos** - Falta de pessoas/budget
- [ ] **Timeline** - Atrasos no desenvolvimento
- [ ] **Comunicação** - Desalinhamento da equipa
- [ ] **Burnout** - Equipa sobrecarregada

### Externos
- [ ] **Regulação** - Mudanças legais (ex: RGPD)
- [ ] **Economia** - Recessão, cortes de budget
- [ ] **Fornecedores** - Mudança de preços/APIs
