# Features do MVP

> Funcionalidades incluídas no Minimum Viable Product.

---

## Princípios do MVP

1. **Resolver o problema core** - Focar no essencial
2. **Lançar rápido** - Validar antes de construir mais
3. **Aprender com utilizadores** - Iterar baseado em feedback

---

### ✅ Incluído

### ❌ Fora do MVP (v2+)

| Feature | Razão para adiar |
|---------|------------------|
| [Feature X] | Nice-to-have, não essencial |
| [Feature Y] | Complexidade alta |
| [Feature Z] | Dependência de features core |
